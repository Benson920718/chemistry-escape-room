# 零號實驗室｜化學密室逃脫專案計畫
## 1. 專案概述
以「研究室封鎖」為敘事主軸，玩家須在 30 分鐘內依序解開六道化學知識謎題，完成解鎖並逃出實驗室。目標對象為國高中初階化學學習者，也可用於課堂暖身、分組競賽及自主複習。

## 2. 學習目標與關卡
| 關卡 | 核心概念 | 學習成果 |
|---|---|---|
| 1 | 元素符號與原子序 | 分辨原子序與原子量 |
| 2 | pH 與酸鹼性 | 依 pH 判讀酸、鹼與中性 |
| 3 | 化學反應式平衡 | 使用最簡整數係數並理解質量守恆 |
| 4 | 密度與浮沉 | 計算質量／體積並比較水的密度 |
| 5 | 物理與化學變化 | 判斷是否生成新物質 |
| 6 | 化學式與原子數 | 讀取下標並計算原子總數 |

## 3. 技術規格
- 前端：HTML5、CSS3、原生 JavaScript（ES6+）。
- 架構：純靜態網站，無伺服器、資料庫或第三方套件依賴。
- 儲存：瀏覽器 localStorage 保存關卡、提示使用次數及倒數時間。
- 版型：CSS Grid、Flexbox 與 Media Queries，支援桌面、平板及手機。
- 部署：Cloudflare Pages；GitHub repository 作為版本來源。

## 4. 規模與功能需求
- 六道線性關卡，需答對才可前往下一關。
- 30 分鐘倒數；逾時顯示失敗畫面。
- 每題最多兩層提示，完成題目後顯示原理解說。
- 顯示解鎖進度、取得的研究紀錄與完成摘要。
- 可從本機儲存狀態繼續遊戲，並可手動重置。
- 所有內容均為模擬教學，不含真實化學實驗操作。

## 5. 非功能需求
- 不需帳號登入，不傳送玩家資料到伺服器。
- 主要操作可用鍵盤完成，按鈕具備清楚文字。
- 小螢幕下採單欄排列，答案欄位不超出視窗。
- 謎題答案與解說需經教師或化學背景人員覆核。

## 6. 驗收清單
1. 首頁可啟動遊戲，計時器由 30:00 開始倒數。
2. 六題正確答案依序為 6811、419、212、5、8、7。
3. 錯誤答案會顯示回饋，且不增加進度。
4. 每題提示可使用兩次，並記錄提示次數。
5. 答對後顯示解說與下一關按鈕。
6. 完成六關顯示完成摘要；倒數歸零顯示逾時。
7. 重新整理頁面可恢復已儲存進度。
8. 桌面與手機瀏覽器均能閱讀與操作。

## 7. 部署設定
Cloudflare Pages 連接 GitHub repository `Benson920718/chemistry-escape-room`，Production branch 選 `main`，Framework preset 選 `None`，Build command 留空，Build output directory 設為 `.`。根目錄需包含 `index.html`、`styles.css`、`game.js`。
